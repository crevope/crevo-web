# Crevo brand assets

All variants of the **Forward-Arrow C** logo, ready to embed in
emails, partner sites, presentations, etc.

**100% self-contained.** Both the mark and the "revo" wordmark are
rendered as outlined SVG paths (no `<text>` elements, no font
dependencies). The file renders identically wherever it's placed —
operating system, browser, email client, presentation tool — regardless
of which fonts are installed. Generated by
`scripts/generate-logo-paths.mjs` from Plus Jakarta Sans Bold.

For in-app rendering use the React component `src/shared/ui/Logo.tsx`
instead — same outlined paths, but the colors inherit via CSS so the
logo adapts to light/dark themes automatically.

## Wordmark (mark + "revo", 160×64 viewBox)

The mark IS the "C" of "Crevo" — no double-C redundancy.

**Proportion intent:** the mark visually dominates (visible height 40 vs
"revo" cap-height ~31, ratio ~1.3:1). The arrow tip sits exactly where
the "r" begins — they read as a single word, not "icon + label".

| File | Mark color | "revo" color | When to use |
|---|---|---|---|
| `wordmark-navy.svg` | navy | navy | Default. Light backgrounds. |
| `wordmark-white.svg` | white | white | Dark backgrounds. |

## Construction reference

ViewBox 64×64 for the mark:

- Implicit circle centered at (24, 32), outer radius 20, inner radius 10
- Opening at angle ±53.13° (cos = 3/5, sin = 4/5 → integer coordinates)
- Arrow tip at (60, 32) — pure horizontal forward vector
- Single filled path:
  ```
  M 36 16 A 20 20 0 1 0 36 48 L 60 32 L 30 40 A 10 10 0 1 1 30 24 Z
  ```

Wordmark: mark at (0, 0)–(64, 64). The "revo" outlined path is
generated from Plus Jakarta Sans Bold at font-size 44 starting at
(60, 52) with letter-spacing -0.025em — produces a path with bounding
box x ≈ 62.7–151.1, y ≈ 27.5–52.5. Cap-height ≈ 31 (smaller than the
mark's visible height of 40, so the mark visually dominates).

To regenerate the wordmark path (e.g. after a font change):

```bash
cd crevo-web
node scripts/generate-logo-paths.mjs
# Paste the printed d="..." into Logo.tsx + every wordmark-*.svg file.
```
